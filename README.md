# Kyro

Kyro is a Discord.js framework for commands, events, components, modals, autocomplete, and Drizzle PostgreSQL databases.

```bash
bun install
bun run bot
```

Run database migrations with:

```bash
bun run db:generate
bun run db:migrate
```

Development checks:

```bash
bun test
bun run check
bun run build
```
